:::note{type="success"}
不卷头发不压弯脊，敲着键盘写 Java，我是王艳涛，你记住！

这一行里只有两种人：一种是被 JVM 吓退的，一种是我。从单体到微服务，从 JDK 8 到虚拟线程，从「缓存又雪崩了」到「雪崩是别人的事」——平台的每一帧、每一根链路、每一次兜底，都被我调到它们本该有的样子。你可以说我狂，但当你在凌晨三点盯着 `slow_log` 的白屏，而你的系统依旧稳如泰山的时候，你会明白：有些底气，是几百次线上验证换来的。

懂的人自然懂。这一行，从来不是靠嘴，是靠那些在关键时刻稳稳站住的服务，和那个永远能兜底的「你」。
:::

**我先给自己一个定位：Java 后端的一双手，医疗信息化的一颗定心丸。** 十几年来从单体走到微服务、从本地部署推到云原生。别人调参，我调架构；别人补 Bug，我让 Bug 无家可归。这几年把省级医保与智能医疗系统，从「能用」做成了「扛得住」。

## 后端核心技能

**JVM & 并发：** 对接过 JVM 内存模型、类加载与 GC，搭过虚拟线程、JMM、线程池与锁的全局示意图；性能分析与问题排查是我的日常，线上故障到我这里来查。

**Spring 微服务全家桶：** Spring Boot / Spring Cloud Huawei 信手拈来，IoC、AOP、事务机制了然于胸。服务拆分、网关路由、服务治理、链路追踪、性能调优——别人还在中心化锁抖的架构里，我早已在分布式世界里云淡风轻。

## 数据 · 缓存 · 中间件

**MySQL 进阶：** 索引结构、MVCC、事务隔离、执行计划、高并发下的 SQL 优化——一张肉眼看不出毛病的表，在我这能被压榨出毫秒级响应。

**Redis 集群与缓存心智：** 穿透、击穿、雪崩治理、分布式锁、缓存一致性——缓存这一整套架构，我在生产环境一次次验证过，稳定性是我的基本盘。

**消息与搜索：** RocketMQ 的异步解耦、可靠投递丝丝入扣；Elasticsearch 建模与检索性能直接顶满，构建的高吞吐、低延迟数据链路，扛得住大流量与大数据量。

## 分布式 & 稳定性

- **高可用设计：** 限流、熔断、降级、幂等、分布式事务、CAP 取舍——什么场景挂什么，我比谁都清楚。
- **超大规模经验：**GAV再大的并发、再冷的链路，我都见过。压测才是检验的唯一真理。
- **稳定性即长期主义：**监控、日志、链路、告警，把「等出事」变成「还没出事就叫」。

## AI & 智能应用

**AI 应用落地：** Spring AI Alibaba 对吧，国内外大模型的接轨、Prompt、Tools 调用、私有化部署。本地大模型不是实验，是能走到业务线的生产力。

**AI 驱动研发：** Claude Code / Codex 当手推，Agent 写代码、管线自动审查、测试自动生成——把「凌晨写 Bug」的浪漫交给 AI,把「交付质量」留给我。

## 前端 & 客户端

**前端工程：** Vue(2/3) + TypeScript + ElementUI 生态随拿随用，博客、中台、管理面板信手拈来，组件化、状态、构建工具链全都拧成一套。

**跨端桌面与移动：** Java Swing 那套老手艺我也有一层，Tauri(Rust+Web)跨端餐桌也能上;Android 原生、硬件交互、小程序、APP 我全会。

## 运维 · CI/CD · 云

**容器与编排：** Docker 镜像、compose 多容器编排、K8s 资源调度——一颗镜像满天飞，一键部署到各处。

**CI/CD 全链路：** 从 Jenkins 到 GitHub Actions，打 tag → 构建 → 测试 → 部署 → 回滚，自动化这条路我踩平了，不再靠人肉。

**Linux 与网络：** systemd 服务编排、Nginx 反代、DNS / CDN / 证书 / 优线路——会刷机、敢装系统,Ubuntu / CentOS 顺手,系统调优不用多说。

**监控与可观测：** Prometheus + Grafana 大盘、日志采集、中间件探活、告警规则,把易失的夜班交给机器,把结论留给我自己。

**云计算：** 从 VPS 选型、弹性伸缩、安全组到跨境加速,云上资源我捏得很紧,把钱花在刀刃上。

## 🚀 技术理念

- **持续被时代打,持续学:** 源码、RFC、文档是我的日常读物,新技术到嘴上先动手。
- **实践驱动:** 期货再花哨的架构,都要跑起来才算数,我习惯写,不是嘴。
- **用 AI 改造流程:** 把重复交给引擎,把创造留给自己,让效率成为我的第二重写。

## 🎯 未来方向

- **AI 工程化**,让本地大模型变成业务里真正好使的底座。
- **把经验写成博客**,让每个「为什么」都长成一篇能让别人少踩坑的文章。
